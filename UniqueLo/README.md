# UniqueLo — Luxury Embroidered Apparel E-Commerce

> **The digital flagship for state-of-the-art embroidered clothing.**  
> Built with React 19, TypeScript, Vite, Tailwind CSS v4, GSAP ScrollTrigger, Lenis Smooth Scroll, and Framer Motion.
