UNIQUELO — CONSISTENT LOGO SYSTEM
This pack replaces the previous inconsistent logo files. Please disregard the earlier pack.

All lockups use one master UL + flowering-branch emblem. The horizontal, stacked and emblem-only
versions reuse the same artwork. The simplified embroidery mark and favicon preserve the same
UL letterform while removing fine details that would not reproduce at small sizes.

Files:
01 horizontal — website desktop header
02 stacked — packaging, social and brand applications
03 emblem — primary symbol / labels
04 wordmark — compact header or footer
05 embroidery mark — simplified stitch-friendly mark
06 favicon — browser/app icon

Every SVG has a transparent background. PNG exports also have transparent backgrounds.
Palette: ink #211B18; flower red #A65349; branch green #66715A; warm gold #D2A45A.

Production note: SVG is vector artwork, not a machine embroidery file. For production,
convert lettering to outlines and have a digitizer create DST/PES stitch files. Fine blossoms
should be omitted or simplified for very small embroidery placements.
