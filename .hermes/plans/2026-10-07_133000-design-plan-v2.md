# UniqueLo Design & Experience Plan v2

> **For Hermes:** This supersedes `2026-10-07_131500-design-elevation.md`. Start here.

## Goal
Transform UniqueLo from a "correct luxury template" into a **new-age Indian embroidery D2C brand** that reads as global, modern, and craft-credible. The site must sell the idea that embroidery belongs on everyday essentials (tees, shirts, sweatshirts, chore coats), that Indian hand-craft is a quality signal, and that every piece is made to last. Launch market: India; secondary: overseas.

## Brand positioning (one sentence)
**"Hand-embroidered essentials. Made in India. Built to last."**

This replaces "Haute Needlecraft" and any overtly ethnic/festive cues. Tone: quiet confidence, technical craft, editorial fashion.

## What we are competing with (reference universe)
- **India:** Suta (handloom storytelling), Jaywalking (streetwear embroidery), NorBlack NorWhite (craft-modern), 11.11 (slow fashion).
- **Global:** Bode (archival craft-as-luxury), Our Legacy (quiet textile focus), SSENSE (editorial e-commerce), A Kind of Guise (small-batch provenance).

We don't copy them; we use their common language: **provenance, process, scarcity, natural materials, fit confidence, editorial photography**.

## What makes the design feel Indian yet modern
- **Typography:** Satoshi (functional) + Melodrama (display). No Devanagari fonts in UI unless the brand name requires it — craft identity comes from content, not decorative scripts.
- **Color:** Warm cream, ink, terracotta, stone. Terracotta is the single accent — reads as earth/clay/India without being saffron or "ethnic."
- **Imagery:** Natural light, fabric texture, hand-in-frame detail shots, craftsperson at work, garment on Indian and global bodies.
- **Language:** Technique names used as features, not categories (Chikankari, Zardozi, Aari, Kantha, Mirror-work).

- No hardcoded hex outside `tokens.css`.
- No shadows added to flat surfaces.
- Accent budget respected: check that only price/stock/CTAs/active underline use terracotta.
- Mobile visual check on one screen width ≤390px.

## Open questions to resolve before/during execution
1. **Category taxonomy** — confirm "Tees + Shirts / Sweaters / Outerwear / Accessories" or different split.
2. **Batch numbering** — real per-product (e.g. 12/80) or same batch for a capsule drop?
3. **Monogram customizer** — initials only, or also motif/position? Affects PDP CTA and cart.
4. **Indian sizing default** — should size selector default to India sizes, or auto-detect by shipping country later?
5. **Payment methods** — COD, UPI, cards, net banking? Affects footer trust signals and checkout (Phase 8+).

## Risks / tradeoffs
- **Scope:** This is ~2.5 working sessions if done straight. The PDP alone is 8 tasks.
- **Photography dependency:** New layouts assume real texture/process imagery. Until then, tonal placeholders + oversized typography will carry the design.
- **Strapi later:** All new fields (`batchNumber`, `craftTechnique`, etc.) must be mirrored in the Strapi content types defined in `docs/07-backend/README.md` during Phase 8. Document each added field.

## Notes on the earlier v1 plan
- Typography system (Satoshi + Melodrama, §12 rules) remains valid.
- Self-hosted fonts stay.
- Anti-generic rules stay.
- Asymmetric composition goals stay, but now anchored by **brand narrative** (craft taxonomy, provenance, batch scarcity) rather than pure layout taste.

Place images in `public/images/products/` following this naming standard (or upload to Supabase Storage bucket `product-media`):
- Front silhouette: `tshirt-[slug]-1.jpg` (aspect ratio 3:4)
- Macro embroidery stitch relief: `tshirt-[slug]-2.jpg` (aspect ratio 3:4 or 1:1)
- Model styling / back view: `tshirt-[slug]-3.jpg`
